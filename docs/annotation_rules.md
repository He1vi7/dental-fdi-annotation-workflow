# FDI 牙框标注规范

## 标什么

每颗**可见牙**一个框，框要包住牙冠和牙根可见部分；类别写 FDI。

- 恒牙：11–18、21–28、31–38、41–48
- 乳牙：51–55、61–65、71–75、81–85
- 阻生/未萌但结构可见：也要框，按对应 FDI
- 缺失：不画框，在 `presence` 写 2/3
- 无法判读：不画框，`presence=5`

## 框的规则

- 一个牙一个框，不合并邻牙；
- 框紧贴牙体，左右留 2–3 像素；
- 不把对颌牙、骨结构框进去；
- 同一颗牙只画一个框；
- 修复体/种植体占位：按对应牙位画框，备注“修复/种植”。

## CSV 格式

统一 FDI 框 CSV：

| 列 | 含义 |
|---|---|
| 文件名 | 图片文件名 |
| FDI | 如 16、46、55 |
| x1,y1,x2,y2 | 原图像素坐标 |
| presence | 1 存在；2 先天缺失；3 获得性缺失；4 未发育；5 无法判读 |
| 备注 | 阻生、修复、乳牙滞留等 |

## 质控

- 前 10 张双标，算 FDI 一致性；
- 重点核对 11/21/31/41（中线）和 18/28/38/48（末端）；
- 乳牙/恒牙混合期，先确认是乳牙还是恒牙，再写 FDI。
